# Security

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](SECURITY.vi.md)

Do not post private API Bearer keys, passwords, local SQLite contents, receipts or unpublished PNGs. Report issues privately by contacting i.am@dangkhoa.dev rather than disclosing exploit details publicly. Temporary Cloudflare Quick Tunnels only expose the password-protected Studio gateway at 127.0.0.1:18789. Public demo passwords displayed in Kaggle outputs must be regenerated for each run and never reused for production.
