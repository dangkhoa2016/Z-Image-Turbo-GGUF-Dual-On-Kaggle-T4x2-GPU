# Contributing

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](CONTRIBUTING.vi.md)

Please open a focused issue before a pull request. Keep each code commit approximately 600 changed lines or fewer. Never add credentials, model weights or generated private images. Link changes to evidence and mark tests as PASS only after executing them. Explain any incompatibility with the Kaggle T4×2 demo. Contributions must respect Apache-2.0 model/vendor licenses and MIT project source.
