# Reproducibility status

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](reproducibility.vi.md)

The repository is intentionally free of large vendored third-party source trees, GGUF weights, safetensors, generated PNGs and private database records. The historical archive branch retains the old initial snapshot for provenance. Notebook dependency installation from a clean Kaggle runtime is NOT YET PASS: exact vendor compatibility must be pinned and tested. The original live Kaggle workspace was a previously prepared environment with verified GPU output. Do not claim that git clone alone restores historic sessions. Preserve authenticated SQLite backups, artifacts and hashes separately if needed. Only mark clean-run PASS after a real dual-GPU end-to-end Kaggle execution.
