# Project contract

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](PROJECT-CONTRACT.vi.md)

## Scope
Deliver a technically convincing but honest Kaggle T4×2 image-generation demonstration, not a general-purpose enterprise service. Use the existing verified dual GPU inference pipeline and user-approved Vue Studio.

## Non-negotiables
Preserve original PASS and NOT_PASS milestone evidence; do not replay passed GPU workloads without necessity; exclude secrets, model weights, personal generated images and runtime SQLite from Git; follow upstream licenses; keep each code commit about 600 changed lines or fewer except lengthy bilingual documentation; maintain mutual EN/VI switch links.

## Demo acceptance
Browser submit to real GPU inference, private SHA256 PNG, View/Download, total elapsed seconds and loading spinner have separate evidence. A new Kaggle notebook environment must pass independently before claiming clean-run reproducibility.
