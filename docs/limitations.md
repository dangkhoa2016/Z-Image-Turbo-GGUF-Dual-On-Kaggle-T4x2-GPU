# Known limitations

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](limitations.vi.md)

This is a demonstration, not a production SLA. Kaggle runtimes expire; Quick Tunnel URLs are temporary; T4 memory and encoder serialization limit throughput. Visual quality adherence cannot be inferred from an API completion. Original benchmark galleries need separate attachment. Users who can read shared notebook output can see the demo password. There is no guarantee that a clean clone will load all original vendored dependencies unchanged. No automatic cloud persistence or DR framework is included.
