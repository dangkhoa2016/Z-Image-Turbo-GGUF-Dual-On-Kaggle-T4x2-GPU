# v1.0.0-demo — Technical Preview

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](RELEASE_NOTES_v1.0.0-demo.vi.md)

This first public technical preview provides the source of a Z-Image-Turbo GGUF Q6_K dual-Tesla-T4 Kaggle demonstration, including a bounded prompt encoder, independent inference workers, authenticated Vue Studio, private PNG receipts and a launch notebook.

### Acceptance and limitations
- Archived dual-GPU, browser click-to-image, elapsed-time UI and HTTPS checks are available as JSON evidence.
- GitHub repository validation is separate from fresh GPU acceptance.
- Historical Pilot32 visual-quality/prompt-adherence gate: **NOT_PASS**.
- Clean Kaggle T4×2 installation and end-to-end replay: **PENDING**.
- Original 48/122 HTML galleries and third-party model weights are not distributed.
- The temporary tunnel URLs and this prerelease do not establish a production uptime SLA.

See [engineering overview](docs/engineering-overview.md), [runtime compatibility](docs/runtime-compatibility.md) and [licensing notices](LICENSE-NOTES.md) for review scope and prerequisites.
