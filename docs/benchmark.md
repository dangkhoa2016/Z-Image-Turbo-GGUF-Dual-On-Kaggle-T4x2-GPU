# Benchmark methodology and evidence

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](benchmark.vi.md)

Fresh validation must measure real T4×2 inference, per-device receipts and browser interaction; source inspection alone is insufficient. Keep runtime seconds, prompt/seed, worker assignment, PNG digest and visual QC separate. The 48-image and 122-image gallery media are distributed in the approved 170-image GitHub Release bundle, not committed as repository source files. The 170-image Release bundle documents the distributed images, not universal visual-quality or prompt-adherence acceptance. Technical inference PASS and human visual-quality results remain distinct. Do not treat code review, screenshots or nominal GPU presence as end-to-end reproduction. Any fresh GPU Run All and independent-account reproduction must be evidenced on the [GitHub Release](https://github.com/dangkhoa2016/Z-Image-Turbo-GGUF-Dual-On-Kaggle-T4x2-GPU/releases/tag/v1.0.0) for its exact source SHA. Do not reuse older render timings as new benchmarks.
