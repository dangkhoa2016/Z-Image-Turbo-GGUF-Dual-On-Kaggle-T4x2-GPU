# Engineering overview and project provenance

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](engineering-overview.vi.md)

The project developed across multiple Kaggle-based experiments before the GitHub publication on 2026-10-16. Prior conversations and locally retained evidence documented initial parallel T4 inference, varied showcase prompts, image quality review, job queue development, authenticated Vue Studio and real browser click-to-render acceptance. The 2026-10-16 Git history rewrite organizes already-authored modules into reviewable commits; it does NOT claim those modules were originally authored at the new commit times. Commit timestamps record the actual rewrite/publication time. Historical visual-QC rejections, including Pilot32 NOT_PASS, remain preserved in project records. A new clean Kaggle replay is a separate future gate.
