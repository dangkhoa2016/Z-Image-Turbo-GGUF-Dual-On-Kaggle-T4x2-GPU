# Triển khai Kaggle

> 🌐 Language / Ngôn ngữ: [English](kaggle.md) | **Tiếng Việt**

Chọn Tesla T4 ×2, bật Internet và attach model GGUF Q6_K cùng dataset hỗ trợ theo README. Chạy notebook tuần tự để clone mã, kiểm tra GPU/model, chuẩn bị thư viện, khởi động API/consumer, mở hai tunnel gallery/Studio. Tài khoản Studio chỉ in để người xem demo sử dụng; không công khai khóa backend. Khi chạy lại notebook phải giữ trạng thái job hiện hữu. URL Cloudflare là tạm thời. Cần attach HTML và ảnh gốc 48/122 trước khi chạy gallery; không thay bằng Pilot32. Việc tái lập đúng toàn bộ phiên bản vendor từ runtime sạch chưa được kiểm chứng.
