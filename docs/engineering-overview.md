# Engineering overview and project provenance

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](engineering-overview.vi.md)

This repository publishes an existing Kaggle Tesla T4 ×2 Z-Image-Turbo GGUF project, developed through multiple prior sessions with GPU tests, image-quality review, job scheduling, browser image generation and an authenticated Vue Studio. The repository was first published on 2026-10-16 from a source snapshot rather than from an original continuous Git development history.

**Git timestamp disclosure:** The 39 publication commits are curated from that source snapshot. Their displayed author and committer dates are deliberately reconstructed into three editorial phases on **2026-10-14, 2026-10-15 and 2026-10-16** for review navigation. These dates and times are **not independently verified creation dates for individual modules or commits**. The true rewrite/publish times and preceding object IDs are retained in the archived Git history and publication audit; they are not represented by the curated timestamps.

The phase labels are infrastructure/inference and tests (October 14), Studio integration and documentation groundwork (October 15), and evidence, documentation and public release preparation (October 16). They describe editorial groupings, not proof of day-by-day code authorship. Historical Pilot32 visual-quality failures remain **NOT_PASS**. Kaggle clean-room replay remains an independent **PENDING** acceptance gate.
